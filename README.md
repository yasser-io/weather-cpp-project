# 🌤️ Weather Monitoring System in C++

A comprehensive console-based weather tracking application built with C++.

## 📋 Features
- ✅ Add weather records with automatic timestamp
- 🔍 Search by date and city
- 📊 Display statistics and analytics
- 💾 Save and load data from files
- 🎯 Generate sample data for testing
- 🗑️ Delete specific records

## 🚀 How to Compile & Run
```bash
# Compile the program
g++ main.cpp -o weather

# Run the program
./weather
